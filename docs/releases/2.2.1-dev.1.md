## 2.2.1-dev.1

Development release built on top of 2.2.0-beta.3 with features and fixes accumulated from the marcd35 fork.

### Improved

- Standardized YouTube embed generation through a shared media-service helper
- Routed embedded playback through Privacy Enhanced Mode using `youtube-nocookie.com`
- Added a visible `Watch on YouTube` handoff from the in-app player
- Documented YouTube embed behavior and legal links in the README
- Added a prompt-friendly Obsidian settings reference under `docs/development/obsidian-settings-reference.md` to speed up settings-tab work without relying on the full `obsidian.d.ts`
- Refreshed the Tags settings auto-tagging UI to use Obsidian-native `Setting` layouts, unified section surfaces, clearer rule/condition cards, and in-place editing that no longer rerenders while typing

### Fixed

- Fixed YouTube embed Error 153 by setting iframe `referrerpolicy="strict-origin-when-cross-origin"`
- Removed unsupported YouTube quality override URL rewriting from the player
- Enforced a minimum 200x200 YouTube player surface to better match RMF requirements
- Added regression tests for YouTube embed URL generation and feed video-id normalization
- Fixed card-view tag overflow by moving tags into a footer-adjacent single-row strip with `+N` compaction, while restoring normal auto-grid density and bounded preview media sizing
- Stabilized card view tag strip and preview media sizing for consistent layout

**Note:** This is a development version intended for feature development and eventual contribution back to upstream. For stable use, see [releases](https://github.com/amatya-aditya/obsidian-rss-dashboard/releases).
